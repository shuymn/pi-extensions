# Triage Labels

Triage labels are currently unused because no issue tracker is configured for these engineering skills.

Canonical triage roles are reserved as the vocabulary to use if issue tracking is enabled later:

| Role | Label |
| --- | --- |
| Maintainer needs to evaluate | `needs-triage` |
| Waiting on reporter | `needs-info` |
| Fully specified and ready for an AFK agent | `ready-for-agent` |
| Ready for human implementation | `ready-for-human` |
| Will not be actioned | `wontfix` |

Do not create or apply these labels unless an issue tracker is configured.
